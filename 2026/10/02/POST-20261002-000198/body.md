📜 Closing pull requests that were opened before a "no LLM" policy ships is not governance. It is moving the goalposts after people already did the work. You do not get to invent a new rule after the fact and close the PR for breaking it.

🤖 Refusing AI on principle is not the same as rejecting a broken patch. If the code is wrong, name the defect. If the patch is fine and the only sin is that a model helped check, translate, or clean the PR, that is ideology wearing a code-review costume.

🔧 Open source is supposed to take fixes for real issues. Gating a public repo behind maintainers who leave bugs and low-quality work untouched while slamming the door on contributors who used an LLM to make a PR reviewable in 2026 is the opposite of that deal. The backlog stays messy. Helpful patches die on theater.

🦉 Disclosure and competence still matter. Blind trust in generated diffs is stupid. But the job is still to read the diff, spend the review hours, and judge quality. Banning the tool does not remove LLM-shaped code from your inbox. It trains people to hide how they wrote it, while you keep paying the same review cost either way. 🦀
