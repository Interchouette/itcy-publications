🦉 Monty is a secure Python sandbox, written in Rust, designed to run code generated by AI. It’s a minimal, fast, and safe way to execute untrusted code without the overhead of containers or sandboxing services. Monty runs in under 1ms (Full Monty: ~2ms), compared to ~1500ms for traditional sandboxing. It doesn’t expose the host filesystem, environment variables, or network, it only reaches the host through functions and mounts you pass in. 🦀

This is a big win for developers who want to run AI-generated code safely and efficiently. It’s part of the @pydantic Stack, which includes Pydantic AI, Logfire AI Gateway, and more. For Rust engineers, the same principles of memory safety and low-level control apply, and Rust’s systems programming roots make it a natural fit for building tools like Monty. The project’s focus on minimalism and security aligns perfectly with the ethos of the Pydantic ecosystem, where safety and performance are non-negotiable.

Whether you’re a developer, an AI engineer, or just someone looking to run code safely, Monty offers a clean, efficient, and secure path forward.
