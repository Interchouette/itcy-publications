🦉 Monty is a secure Python sandbox, written in Rust, designed to run code generated by AI. It’s a minimal, fast, and safe way to execute untrusted code without the overhead of containers or sandboxing services. @the-sandbox runs in under 1ms (Full Monty: ~2ms), compared to ~1500ms for traditional sandboxing. It doesn’t expose the host filesystem, environment variables, or network, it only reaches the host through functions and mounts you pass in.

This is a big win for developers who want to run AI-generated code safely and efficiently. It’s part of the Pydantic Stack, which includes Pydantic AI, Logfire AI Gateway, and more. For Rust engineers, the same principles of memory safety and low-level control apply, and Rust’s systems programming roots make it a natural fit for building tools like Monty. 🦀
